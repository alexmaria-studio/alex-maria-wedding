# Alex & Maria — Wedding Invitation Website

A responsive, luxury-editorial wedding invitation concept set in Lake Como, Italy.

## Project files
- `index.html` — page structure and invitation copy
- `style.css` — complete responsive design
- `script.js` — mobile menu, live countdown, and demo RSVP response
- `images/couple.png` — supplied couple image
- `images/ring.png` — supplied engagement image
- `images/venue.png` — supplied venue image

## GitHub Pages deployment
1. Upload the files and the entire `images` folder to the root of your `alex-maria-wedding` repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. Wait for GitHub Pages to publish the site.

## Before a real event
The names, date, times, deadline, and venue wording are sample details. Update them to the real event. The RSVP form is a front-end demonstration and does not send or save responses.
